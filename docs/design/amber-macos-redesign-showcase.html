六大 macOS Agent 标杆案例与人因工程映射

提炼桌面端顶尖 AI 与效率工具的交互原语，并转化为 Amber macOS 的具体代码改进。

01 — CLAUDE DESKTOP × 渐进披露

羊皮纸三阶色温与内联思考胶囊

用 #FAF8F3 主画布与 #F3F0E8 侧栏建立温和纸张边界；将思考过程与工具调用封装为 26pt 内联轨迹胶囊，消除阅读区视觉干扰。

02 — CURSOR AGENT × FITTS'S LAW

输入框就近模型切换与胶囊开关

将模型选择器内联至输入框底部右侧，鼠标移动距离缩短 75%；以一体化触感胶囊（DesktopToggleChip）替代生硬的表单小滑块。

03 — LINEAR × OCCAM'S RAZOR

检查器三段透镜与零空态噪音

右侧检查器顶部新增「全部 / 工作台 / 上下文」透镜切换；将三段冗长空状态合并为「回顾 — 追问 — 压缩」快捷胶囊行，消灭刺眼系统蓝链接。
