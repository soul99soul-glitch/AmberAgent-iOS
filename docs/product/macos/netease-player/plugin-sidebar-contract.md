# Amber macOS 侧栏插件双形态规范

适用范围是原生插件摘要卡和 Plugin v3 侧栏／检查器视图。网易云和飞书日历是本轮代表；其他插件可以按其业务逐步提供更丰富的状态，不虚构业务数据。

## 展开态

- 容器默认撑满侧栏并以宽高约 1:1 展示；单层标题／状态、核心内容、真实指标、主要操作依次组织，次要功能进入内部二级视图。内容超出时允许在插件内部滚动，不裁切并假装已完整展示。
- 建议 16 pt 内边距、12 pt 主区间距，正文至少 11–12 pt；主操作约 40–44 pt，次操作约 32–36 pt。长文本截断时应保留可访问名称与查看完整内容的途径。
- WebView 插件可声明 `aspect_ratio`（宽除以高）做适配；未声明时默认 1:1。旧视图被限制在方形卡片内的可滚动区域，插件应自行调整固定高度或不可滚动的页面。

## 收起态

- 默认是与飞书等侧栏卡片一致的横向圆角矩形：约 56–64 pt 高、14–18 pt 圆角。左侧图标或缩略内容，中间主信息及一条真实副状态，右侧最多一个主操作；文本单行省略。点击左侧展开，右侧主操作不能同时触发展开。
- 网易云显示歌曲、歌手或播放状态，以及播放／暂停；仅真实播放且获得有效时长和进度时可显示 2 pt 进度。任务／自动化可显示任务、阶段、暂停／继续；下载可显示文件、进度、暂停；同步可显示最近同步或待处理数、同步状态；纯工具可显示真实启用／配置状态及打开入口。错误态优先短原因及修复入口。
- 无业务状态接口的旧 WebView 默认展示清单标题、真实“已启用”状态和“打开”，不会把虚构数字或假进度当成业务数据。它只是兼容回退，具体插件仍需声明并渲染自己的 compact 数据，才能满足对应业务信息层级。

## 生命周期与交互

- 自定义 compact 的插件声明 `compact_height`，使用 `data-amber-presentation` 同一文档变形；未声明的旧 WebView 在收起时保持挂载但隐藏，展开时恢复。原生摘要卡读取同一宿主快照。后台任务的生命期由原有运行时负责，不随视图折叠停止。
- 变形约 240 ms；主元素在同一文档中通过 `data-amber-morph` 保持视觉身份。原生摘要图标使用匹配几何；旧 WebView 使用淡变回退，不擅自改写其业务内容。网易云当前收起时即时隐藏挪动过的次要控件，避免 WebKit 暂停淡出时与主信息叠压；展开时再淡入。系统开启减少动态效果时不做位移或缩放。保证焦点与无障碍名称、对比度、长文本、错误及空态；不可用的操作应禁用。
- 搜索在方形卡片内从入口展开，输入立即获得焦点，结果轻微淡入；返回不清空业务或搜索状态。快速反向操作要取消旧动画并落在最新状态。
- 插件只在确有来源与有效值时展示进度，不在空态、错误态或无时长时保留灰线。具体插件须按 unslop 和 Amber 现有视觉语言适配。

## 迁移清单

- 网易云：已声明方形比例和专用 compact；真实账号搜索、音频、进度、播放按钮与变形前后状态尚需端到端验收。
- 飞书日历：本轮以已有事件快照、真实空态和打开工作台入口提供通用 native compact；跨日期条目显示日期。Debug 窗口已目视核对其空态 mini 和方形展开态，现有快照定点测试通过；真实日历同步未另行验证。
- `examples/plugins/kanban-board`：旧 WebView 获得通用收起回退及实例保留；应后续声明 compact，展示真实进行中任务和有意义的单一操作，并检查原页面的方形滚动表现。
- 其他第三方 v3 侧栏／检查器视图：回退只能反映已启用，不能自动知道业务状态；按插件职责迁移 `compact_height`、状态与适合的主操作，测试长文本和输入保留。现有非插件上下文、产物架等面板不在本轮迁移范围。
