# 六个方向（秒数 27 → App 分区 4 号「友好金融」，东亚分区 4 号「上海摩登」）

共同输入：spec.md、assets/amber-icon.png（黑色几何 A + 铜色尖塔）。六版同内容、同尺寸（1440×900 窗口），只换设计。

## D1 · 最佳设计师｜原研哉｜「琥珀含光」（安静）
- 借的：留白是主角；材质本身说话；字极少极小；颜色几乎只有白和一种材质色。
- 主角素材：琥珀的「透光」——生成中的消息、选中的会话、发送键都是一块半透明蜂蜜色光晕（radial-gradient + 微弱内发光），其余全是近白纸面 #FAFAF7 与 1px 发丝线。
- 骨架：侧栏无底色，只用发丝线与留白分区；正文 680px 窄栏，行距 1.8；顶栏几乎透明，只有标题与一个模型文字按钮；输入器是一条细线框长条，不是大灰框。
- 胆量：整个窗口只有一处有颜色——当前正在发生的那件事（生成中/待审批）。
- form：Amber 是能把光封在里面的树脂——「正在进行」的东西才发光。

## D2 · 最佳设计师｜Panic（Nova / Transmit 团队）｜「有性格的原生」（大胆）
- 借的：Panic 的 Mac app 把原生控件做得有体温：饱和但不刺眼的品牌色、带插画感的图标、圆润分段控件、侧栏里每个条目有自己的彩色小徽记。
- 主角素材：从 logo 的尖塔延展出的「A 徽记」系统——每个会话一个由几何三角构成的彩色小徽记（6 种暖色），空态是一枚大号立体的 A 尖塔（CSS 3D/渐变）。
- 骨架：侧栏有温暖的磨砂底（vibrancy 模拟），顶栏是分段控件（对话 / 文件 / 任务）+ 右侧模型胶囊；工具卡是带彩色侧标签的圆角卡；输入器是带内阴影的圆角面板，发送键是饱和琥珀橙 #F28A1E 圆角方块。
- 胆量：会话徽记与工具卡的颜色编码。
- form：Logo 的三角尖塔成为整个图形语言的「笔画」。

## D3 · 现实参照｜Raycast for Mac（同媒介，未截图，凭对产品界面的了解）｜「键盘优先 · 深色」（中性/大胆）
- 借的：近黑画布 #0B0C0E、面板 #141518、发丝边 #26282B；用色阶而不是阴影分层；每个动作右侧对齐键帽（⌘K、⌘↵、⌘.）；分组小标题；选中行浅灰高亮。
- 主角素材：键帽与快捷键本身；输入器就是一个命令面板（输入 / 召唤工具和模型，下方显示建议列表）。
- 骨架：主稿深色；侧栏窄（240），会话行单行 + 右侧时间；正文是等宽+无衬线混排，工具卡像终端日志块；审批卡内嵌键帽「↵ 批准 / ⌫ 拒绝」。琥珀 #E8A54B 是唯一强调色，只给光标、生成中、主按钮。
- 胆量：把输入器做成命令面板。
- form：Amber 是开发者整天开着的工具，键盘就是它的主语。
- 附一张浅色缩略。

## D4 · 现实参照｜Things 3 for Mac（Cultured Code，两获 ADA；未截图）｜「挺括的纸」（安静）
- 借的：纯白 + 近黑字 + 一个强调色只给勾选/加号；缩进发丝线（从图标右侧起）；分组标题小号粗体；展开的条目变成带大阴影的浮起卡片。
- 主角素材：浮起卡片——审批卡和工具卡是从时间线里「抬起」的白卡（双层阴影 0 2px 6px + 0 24px 56px），其余全平。
- 骨架：侧栏浅灰 #F5F5F7，分组「今天 / 本周 / 更早」，置顶用小星；会话行两行（标题 + 一行灰预览），无条数；正文 720；强调色改为琥珀 #C2702A（替 Things 的蓝）。
- 胆量：只有需要人决定的卡片才浮起来。
- form：Agent 时间线里大多数事自动完成，只有审批要你动手——它就该跳出纸面。

## D5 · 秒数轮盘｜App 4 号「友好金融 Monzo 式」→ 迁移为「暖色满版」（大胆）
- 借的：满版品牌色区 + 白色圆角抽屉面板；34px 大圆角；胶囊按钮；粉彩色块分类；口语化小标题。
- 主角素材：侧栏是一整块满版琥珀 #E9893A→#D9702B 渐变，白字；会话列表在其上；正文区是从右侧抬起的白色大圆角抽屉。工具卡用粉彩底（黄 #FFE3A6 读取、蓝 #CFE6FF 搜索、粉 #FFD3D3 待审批）。
- 骨架：圆润的人文无衬线（Figtree 或系统圆体退回 SF Pro Rounded 感），大标题 28px；输入器是大圆角白胶囊 + 圆形琥珀发送键。
- 胆量：满版琥珀侧栏。
- form：「Amber」这个名字直接做成整片颜色。

## D6 · 秒数轮盘｜东亚 4 号「上海摩登装饰艺术」→ 只借色彩与几何（大胆，最多这一版用力）
- 借的：深墨绿 #17352F + 金 #C9A24A（与琥珀同族）+ 米黄纸 #F3ECDD；放射扇形与阶梯几何；双框线（金外框 + 深内线）。不借月份牌插画与美术字。
- 主角素材：空态是一枚由 logo 尖塔放射出的扇形光芒（SVG）；侧栏深墨绿底、金色发丝线分组；选中会话左侧一个金色阶梯形标记。
- 骨架：正文米黄纸面，标题用中文宋体（Songti SC / Noto Serif SC），正文无衬线；工具卡双框线；发送键是金色八角形。
- 胆量：墨绿 + 金的配色与放射几何。
- form：琥珀与金同族，「摩登」对应一个新时代的工具——但只在色和几何上借，信息仍清楚。
