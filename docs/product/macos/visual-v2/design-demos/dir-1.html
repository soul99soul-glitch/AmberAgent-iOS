把 stdio 传输改成走登录 shell 的 PATH，同时别破坏进程组回收。

读取文件report.md docs/mcp · 214 行 · 0.3 秒

看完报告，问题在于 GUI 启动时拿不到登录 shell 的 PATH。改法分三步：

  • 启动时用登录 shell 解析一次 PATH，缓存到进程生命周期，超时 2 秒回退系统默认。
  • 子进程仍走 posix_spawn 并设新进程组，killpg 才能整组回收。
  • 不要用 zsh -l -c 包住 server 本身，否则 shell 会成为组长、吞掉信号。
StdioTransport.swift
var attr = posix_spawnattr_t()
posix_spawnattr_init(&attr)
defer { posix_spawnattr_destroy(&attr) }
// 新进程组：killpg(pgid, SIGTERM) 能整组回收
posix_spawnattr_setflags(&attr, Int16(POSIX_SPAWN_SETPGROUP))
posix_spawnattr_setpgroup(&attr, 0)

env["PATH"] = try await LoginShell.resolvedPATH()  // 只解析一次
等待你批准：执行 shell运行已暂停
