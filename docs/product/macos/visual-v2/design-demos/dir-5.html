上次的排查记录确认了原因：从 Finder 启动时 App 拿不到登录 shell 的 PATH，所以 npx 找不到。改法分三步：

  • 启动时用 zsh -lic 解析一次登录 PATH 并缓存，不在每次 spawn 时起 shell。
  • 子进程仍由 posix_spawn 直接启动，不套一层 shell，进程组归属不变。
  • 断开时向整个进程组发 SIGTERM，2 秒后仍未退出再补 SIGKILL。
StdioTransport.swiftSwift
let env = try await LoginShellEnvironment.resolved()  // 只解析一次，之后走缓存
var attrs = posix_spawnattr_t()
posix_spawnattr_init(&attrs)
posix_spawnattr_setflags(&attrs, Int16(POSIX_SPAWN_SETPGROUP))
posix_spawnattr_setpgroup(&attrs, 0)  // 子进程自成一组，回收时整组发信号
let rc = posix_spawn(&pid, executable, nil, &attrs, argv, env.cStrings)
