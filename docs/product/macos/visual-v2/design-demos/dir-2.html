看了 report.md 里的复现记录，问题在于从 Finder 启动时继承的是 launchd 的精简 PATH。改法分三步：

  1. 用登录 shell 启动：以 $SHELL -l -c 包一层，读取用户 profile 里的 PATH。
  2. 用 exec 替换 shell 进程：MCP server 直接接管 pid，stdin/stdout 管道不经过中间层。
  3. 启动后立刻建进程组：停止时向整组发 SIGTERM，子进程不会变成孤儿。
SwiftStdioTransport.swift 
let shell = ProcessInfo.processInfo.environment["SHELL"] ?? "/bin/zsh"process.executableURL = URL(fileURLWithPath: shell)// -l 读取登录 profile；exec 让 server 接管 pid，管道直连process.arguments = ["-l", "-c", "exec " + command.shellQuoted()]try process.run()setpgid(process.processIdentifier, 0)   // 独立进程组，stop() 时 kill(-pid, SIGTERM)
