重构 MCP stdio 传输 新会话
把 stdio 传输改成走登录 shell 的 PATH，同时别破坏进程组回收。
Amber Claude Sonnet 4.5 · 思考 12 秒
读取文件 docs/report.md 214 行 · 0.3 秒

崩溃记录显示，GUI 进程继承的是 launchd 的精简 PATH。改三处，进程组语义不变：

  1. 启动时用 $SHELL -l -c 'printenv PATH' 解析一次登录 shell 的 PATH 并缓存。
  2. 仍用 posix_spawn 直接拉起 server，只注入 PATH；别包一层 sh -c，信号到不了孙进程。
  3. 保留 POSIX_SPAWN_SETPGROUP，关闭时整组 SIGTERM，2 秒后仍在再 SIGKILL。
StdioTransport.swiftSwift 
func spawnServer(_ argv: [String], env: [String: String]) throws -> pid_t {
    var attr = posix_spawnattr_t(); posix_spawnattr_init(&attr)
    defer { posix_spawnattr_destroy(&attr) }
    // 自成进程组：关闭时 kill(-pgid, SIGTERM) 整组回收
    posix_spawnattr_setflags(&attr, Int16(POSIX_SPAWN_SETPGROUP))
    posix_spawnattr_setpgroup(&attr, 0)
    let path = try LoginShell.resolvedPATH()   // 解析一次，进程内缓存
    return try Spawn.run(argv, env: env.merging(["PATH": path]) { $1 }, attr: &attr)
}
