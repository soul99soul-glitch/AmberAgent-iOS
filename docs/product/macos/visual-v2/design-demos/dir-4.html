重构 MCP stdio 传输amber-mcp · 6 次工具调用

把 stdio 传输改成走登录 shell 的 PATH，同时别破坏进程组回收。
Amber14:31
读取文件report.md 128 行 · 0.2 秒

report.md 里的崩溃记录说明了原因：从 Dock 启动的 App 只继承 launchd 的精简 PATH，找不到 nvm 装的 npx。改法分三点：

  • 用 $SHELL -l -c 启动，PATH 与终端一致，Homebrew 和 nvm 的命令都能找到。
  • 命令前加 exec 让 server 替换掉 shell，pid 和进程组保持不变。
  • 回收照旧对整个进程组发 SIGTERM，3 秒后补 SIGKILL，不留孤儿进程。
StdioTransport.swift
let shell = ProcessInfo.processInfo.environment["SHELL"] ?? "/bin/zsh"
process.executableURL = URL(fileURLWithPath: shell)
// -l 读取登录配置；exec 让 server 接管 shell 的 pid
process.arguments = ["-l", "-c", #"exec "$0" "$@""#, server.command] + server.args
try spawnInNewProcessGroup(process)   // 回收：kill(-pgid, SIGTERM)
