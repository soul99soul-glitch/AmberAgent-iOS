把 stdio 传输改成走登录 shell 的 PATH，同时别破坏进程组回收
Amber15:42 · 思考 6 秒

看完 report.md，现在的问题是 StdioTransport 直接继承了 App 的环境变量，GUI 启动时拿不到 Homebrew 和 nvm 的路径。改法分三步：

  • 启动时解析一次：用 zsh -l -c 读出登录 shell 的 PATH 并缓存，不在每次 spawn 时起 shell。
  • 进程组不变：子进程仍用 posix_spawn + SETPGROUP 启动，killpg 回收无需改动。
  • 失败可回落：超过 2 秒或解析失败时用系统默认 PATH，并记一条警告日志。
SwiftTransportEnvironment.swift
static func resolveLoginPATH(timeout: Duration = .seconds(2)) async -> String {
    let shell = ProcessInfo.processInfo.environment["SHELL"] ?? "/bin/zsh"
    // 只用于读取 PATH，不参与 MCP 子进程的进程组
    let output = try? await Shell.run(shell, ["-l", "-c", "printf %s \"$PATH\""])
    return output?.trimmed ?? TransportEnvironment.fallbackPATH
}
