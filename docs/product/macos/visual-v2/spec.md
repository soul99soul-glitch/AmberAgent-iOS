# Amber macOS 视觉升级 · spec

## 是什么
Amber 是一个原生 macOS（SwiftUI）AI Agent 客户端：多会话聊天、多模型、工具调用（文件/搜索/shell/MCP）与审批、Workspace 文件、子代理与模型议会、记忆与 Skills。用户是重度使用的个人开发者/知识工作者，一天开着好几个小时。

## 品牌资产（现有，必须沿用）
- Logo：assets/amber-icon.png —— 黑色几何「A」，中间一枚琥珀/铜色尖塔（#B06A45 一带）。这是唯一的品牌图形。
- 现有强调色：浅色 #A0602A，深色 #D5AC7B（琥珀/铜）。可以调，但要保持「琥珀」这个名字的温度。
- 当前截图：assets/current.png（侧栏+空态+输入器，被评价为「整体很丑」）

## 当前问题（来自截图）
- 侧栏：会话行信息堆叠（标题/预览/时间/条数四行），选中态是灰块，层级弱；「搜索会话」框和顶部按钮挤。
- 顶栏：模型名胶囊、标题、右侧 6 个灰图标一排，无分组，像工具条堆砌。
- 空态：一个大灰 A 加两行字，悬在大片空白里，没有设计。
- 输入器：一个巨大的灰框，附件/工作区/上下文/工具四个图标散在左下，发送按钮是棕色圆，和整体不协调。
- 整体：灰对灰，没有材质、没有节奏，字重单一，像未完成的系统表单。

## 要设计的画面（三个方向统一画这些，1440×900 窗口内）
1. 主窗口·进行中会话：侧栏（今天/更早分组，6–8 个会话，含一个生成中、一个置顶）、顶栏（会话标题 + 模型选择 + 工具入口）、对话正文（用户消息、助手回答含一段 Markdown 列表与一个代码块、一张工具调用卡「读取文件 report.md」已完成、一张等待审批的卡「执行 shell: npm test」带批准/拒绝）、底部输入器（含附件、模型/推理、工具开关、发送/停止）。
2. 空态（新会话）：问候 + 3–4 个起手建议 + 输入器。完整版可在同一 HTML 内用切换按钮展示。

## 内容（真实中文，不用 Lorem）
会话标题示例：「重构 MCP stdio 传输」「季度营收数据整理」「Amber 发布说明草稿」「SwiftUI 列表性能排查」「读论文：Mixture of Depths」「周末去杭州的行程」。
当前会话：「重构 MCP stdio 传输」，用户问「把 stdio 传输改成走登录 shell 的 PATH，同时别破坏进程组回收」，助手回答带 3 点列表 + 一段 Swift 代码 + 工具卡。

## 约束
- 这是 macOS 原生 App 原型：要能用 SwiftUI 落地（材质、圆角、SF Symbols 风格图标、系统字体或可内嵌字体）。不是网页落地页。
- 正文 ≥14px，标签 ≥12px，对比度 ≥4.5:1。浅色为主稿；每版附一张深色缩略。
- 不用 emoji 图标、不用紫渐变、不画人像。
- 输出：design-demos/dir-N.html，单文件，截图 1440×900。
