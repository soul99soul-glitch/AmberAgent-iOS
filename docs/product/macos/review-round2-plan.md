## 复核为假阳性或不改

- 审批决定未「一次性消费」：call id 由服务商唯一生成，同 id 不会二次派发；不改。
- 设置页 Temperature 行被底栏「截住」：Form 自身滚动，底栏在 Form 外，不覆盖。
- 工具栏标题未与正文栏对齐：macOS 原生行为。
- 深色工具栏灰带：离屏截图的窗口装饰绘制；已设纸色背景，实窗再核。
- 停止/删除/切换/标题生成/退出写盘/导入新 UUID/备份回滚：review 逐条追踪无缺陷。
- shell 超时进程组回收、路径越界与符号链接、子代理只读、Recipe 失败停止、通知只在落盘后：无缺陷。
