# 智能 UI：从决策卡扩展到任务界面

日期：2026-10-12。状态：A—D 源码、独立审查、受影响回归及签名构建已完成；最终真机更新被设备连接阻断，真实 provider 与真机交互验收尚未通过。沿用上一轮的组件、来源标识、草稿保存和显式提交链路，不把上一轮装机记录当成本轮交付证据。

## 目标与依据

真实使用发现：“用智能 UI 帮我记忆明朝十六帝”生成了 HTML 封面和“打开 Live 演示”，学习交互没有出现在对话中。当时协议只支持 decision，模型提示又限制必须存在未决方案才生成任务卡。80 种组件未能解决任务类型不足。

Agent 应根据任务判断界面是否能降低操作成本。学习、反复浏览、填写信息和比较选择优先使用合适的原生界面；一句话能解决的问题、用户明确要求纯文字，以及已经获得授权的直接执行任务仍直接处理。用户不必知道协议或点名组件。

## 实施范围

- 保留 decision：真实方案比较与单选，不替用户选择。
- 增加 form：为当前任务收集必要输入，填写后显式继续，无虚构方案。
- 增加 explore：通过已有 tabs、accordion、列表和输入组件组织浏览与参数选择；只提供宿主已有的本地行为，不宣称可以运行任意计算公式。
- 增加 study：消息内复习、翻卡、选择题、判分、解释和进度，支持重新练习及离开后恢复。模型提供学习内容与答案，宿主执行确定性交互。

SVG、Three.js、HTML、slides 和独立 MiniApp 保留各自用途。只有确实需要其能力或用户明确要求时才选择这些路径；普通学习交互不再以 HTML 封面替代可直接操作的任务界面。

## 阶段与验收

### A：协议与状态闭环

扩展任务种类，去除非决策任务的强制方案选择；学习内容、答案与本地会话有清晰数据契约。旧 decision、旧草稿及提交记录可继续读取。学习进度按来源保存，提交包含本次真实练习摘要，复用原有保存后运行的调用链路。

检查：协议校验、错误答案引用、旧记录兼容、无需选择的提交、学习切换／答题／重练、草稿写盘恢复、冻结摘要和来源隔离。完成后独立 subagent review。

### B：聊天内原生体验

学习卡直接显示复习和测验；本地翻卡、作答和切题不请求模型。复用原生组件支持 form/explore，空问题和空选项不占布局；44pt 操作区域，窄屏、暗色、大字体无重叠。UI 解码在生命周期进行，不能放进 body。

检查：实际控件行为、恢复后的当前题、提交快照、默认 NativeChatTimelineView 呈现，以及代表性截图。完成后独立 subagent review，修复确认的问题。

### C：Agent 自主选择与生产验证

提示说明界面选择原则、四类实际能力及合法示例；不增加关键词强制路由或用户开关。真实模型使用自然请求“用智能 UI 帮我记忆明朝十六帝”，不在用户消息中指定 JSON/schema。验证输出为可解析的 study 卡，真实学习结果能进入下一轮；另核对普通问答、明确文字请求、SVG／slides／MiniApp 保持可用。

运行受影响任务测试及项目规定的聊天／滚动／viewport／row cache 回归；在构建窗口可用后生成项目和构建。真机更新需保留已有设置并协调设备占用。分别记录源码、模拟器、真实 provider、安装／启动、实际真机交互的结果；设备或 provider 阻断如实记录，不用 hosting 或 fixture 测试替代。

### D：真实生成过程与参数联动

用户进一步指出组件缺少可视化过程。生成中的任务卡应逐步展示已经接收到、结构完整且通过校验的标题与内容；未完成结构不猜测补全，不显示虚构百分比，不写入草稿。生成完成后才开放交互；取消或失败不保留“正在生成”的假状态。

随后补齐同一卡片内数字输入对指标、进度及图表的直接联动。用明确字段引用读取本卡草稿；预览初值只负责展示，显式操作才进入提交。非法输入显示原因，不画成零。保留学习卡已有的真实答题进度，不增加任意表达式或脚本运行环境。

按生成预览、参数联动两个步骤实施，每步完成后独立 subagent review。核对分片、重写、完成、失败及取消，复用项目要求的聊天回归，并检查窄屏、暗色、大字体和互动后的布局。

完成后只对本轮实现做一次有限可维护性检查。分别交付当前构建、安装启动与真实交互证据；阻断项如实记录。

## 实施结果与交付边界

四类任务界面已接入原有 80 种组件。study 在聊天消息内执行翻卡、作答、判分和重新练习；学习摘要沿草稿保存、显式提交、会话消息与 agent 运行的既有链路继续。form/explore 不再显示虚构选项，也不要求先选择方案。

生成过程已经接线：收到并闭合、通过校验的内容逐段呈现，显示真实收到的项目数量；生成期间保持只读，成功终态后转为正式任务卡。数字字段与本卡指标、进度和图表直接联动，非法输入显示原因并阻止提交。

实际请求发现，旧的“时间线”规则会强制 SVG 并拒绝合法原生卡。当前在明确指定智能 UI 的普通请求及可信任务卡继续消息中选择原生路径；明确 SVG、HTML、PPT 等媒体请求继续使用相应路径，拒绝智能 UI 的请求也保留原行为。普通任务的自主选择由模型能力提示完成，不将所有主题硬编码为卡片。

各阶段均已独立复核。已修复学习答案的显示对比度、生成预览提前接受非法学习项、数字精度丢失、窄屏大字号图表末项截断和卡片父标识覆盖子控件等实际问题。真实控件验收覆盖学习、数字联动、重置、来源归属和显式提交；固定 fixture 只证明生产控件与宿主 owner 的行为，不作为真实 provider 或持久化验收的替代。

最终回归、签名产物及设备状态见本轮交付记录；自然学习请求的真实 provider 输出、真机卡片操作和完整持久化验收仍需相应环境实际通过，不能由源码或截图推定。
