# Jev 1.14 与手机截图判断

目标：Amber 能明确选择 `jev-1.14.0`，把需要 Jev 判断的手机当前截图与界面文字一起发送，在同一次决策中选择已有候选。唯一候选、本地效果验收和后续确定步骤继续本地执行。

## 官方契约（2026-10-16 核对）

- [发布说明](https://typesafe.ai/blog/jev-1-14)：`jev-preview` 指向 1.14，`jev-latest` 暂指向 1.13；图片和 Box 尚属实验能力。
- [图片接口](https://docs.typesafe.ai/images)：原生 `assets` 引用与 `TypeSafe-Danger-Zone-Images: true`；PNG/JPEG，每边 280–1568 像素。图片引用在状态中只出现一次，避免重复展开。
- [Box](https://docs.typesafe.ai/primitives/box)：1.14 返回归一化四边与 confidence；目标不存在时也会返回 Box，所以不能单凭 Box 发起点击。
- [Vercel 发布说明](https://vercel.com/changelog/typesafe-ais-jev-1-14-is-now-available-on-ai-gateway)与[固定 SDK 源码](https://github.com/vercel/ai/blob/8a5233b15b1e69573d63faee6cd0014559252ee4/packages/gateway/src/gateway-decision-model.ts)：Gateway 使用 `typesafe-ai/jev-1.14.0`、`/v4/ai/decision-model`、`stateParts` 和规格版本 4。图片在原状态位置转换为带 base64 数据的 file part；Gateway 不支持 Box。

## Phase 1：原生请求与协调器

- 扩展原生图片 assets、实验 header、Box 答案解析与坐标校验；原生纯文字保持原协议，Gateway 按当前 SDK 升级为 decision-model 协议。
- 图片请求沿现有协调器的范围、配置 revision、日用量预算与 deadline；采用 2 MiB 的应用级上限，不放大纯文字请求的 64 KiB 限额。
- 图片判断不缓存，避免复用旧画面；未授权分节及其图片均不得进入批请求。
- 验证：两种 wire、图片权限、请求字节预算、Gateway 状态和图像顺序及不支持的题内引用/Box 拒绝、Box 非法答案。
- 独立子代理审查协议和调用链，修复确认的问题。

## Phase 2：手机生产调用链

- 在现有实际调用 Jev 的路径中惰性获取绑定观察 ID 的新鲜截图；不增加一轮文字试探。
- 后台将截图归一化为 upright JPEG，保持全图，限制长边；资产与当前观察明确关联。
- 截图权限独立且默认关闭；获取失败、观察不匹配、撤销权限或取消后，不能继续执行旧候选。
- 保持现有本地验收权威性和仅选择可执行候选的边界，不凭 Box 生成动作。
- 验证：服务和工具集成；本地唯一候选零截图/零 Jev，带图选择单次请求。
- 独立子代理审查真实工具入口、配置撤销及动作后验收。

## Phase 3：设置与验收

- 无固定版本时测试 1.14；保留已有固定模型，提供“测试并升级至 Jev 1.14”，成功且返回版本一致后才固定。
- `jev-preview` 与 `jev-latest` 都是浮动别名，不视为已验收固定版本。
- 两个手机用途分别展示截图范围；原生以及明确固定的 Gateway 1.14 可用图片，旧 Gateway 模型显示升级提示。图片能力标注实验。
- 验证设置持久化、运行时消费、普通/窄屏/辅助功能字号截图；子代理审查布局和调用闭环。
- 收尾仅对本轮 diff 做一次可维护性检查，核对四个既有 Intelligent UI WIP 未变。

## 完成记录

- Phase 1：原生与当前 Gateway 协议、精确字节预算、权限过滤及图片禁用缓存均已接通；独立子代理两轮审查（含 Gateway 增量）未发现剩余确认问题。
- Phase 2：三个真实工具入口均注入绑定观察的惰性截图；Runner 客户端本地 HTTP 集成覆盖图片选择、原 ref 派发及本地完成，也覆盖唯一候选零截图/零 Jev。服务与图像处理的独立审查通过，非对称像素测试验证了实际方向。
- Phase 3：两种 API 的 1.14 测试升级、固定版本持久化、截图范围及六语文案已完成。子代理检查普通、窄屏、大字号、俄语及 Gateway 状态截图，发现并修复截图图标随字号变大导致的列不齐；三张修复后截图复核通过。
- 验证：完整签名门禁 545 项中 544 通过，1 项旧 Gateway 测试仍断言旧字段；修正该测试契约与 UI 图标后，受影响的协调器及界面 38 项全部通过。两轮按测试 ID 合并的最新结果为 545 项通过；这是完整门禁加定点重跑，不是第二次完整运行。
- 四个既有 Intelligent UI WIP 按 SHA-256 保留且排除出验证构建；本轮代码和资源输入在主工作区与隔离验证工作区一致。
- 真机交付：Release 构建及五个应用/扩展的严格签名校验通过，已覆盖安装到 iPhone 18 Pro（iOS 27.2），正常启动后再次确认进程存活。安装前后的会话目录 391 项、App Group 目录 3 项的名称、大小和修改时间一致；六项关键设置安装前后及正常启动后内容一致，其中本地设置在启动时重新序列化，解码内容不变。未读取会话正文或 Keychain。

真实 TypeSafe/Gateway 云端图片判断与多邻国整题耗时尚未验收。既有固定模型和截图外发选择保留，升级入口测试成功后才切换版本；图片范围需要用户按用途选择。
