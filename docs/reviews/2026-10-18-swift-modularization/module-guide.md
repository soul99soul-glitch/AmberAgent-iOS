# iOS Swift 职责导航

[AppShell](../../../iosApp/iosApp/AppShell.swift) 装配依赖与页面。以下 `extension` 仍属于原类型，不新增状态 owner；测试名均在 `iosAppTests/`。旧测试类拆分的完整选择入口见 [Phase 4](phase-4-test-entrypoints.md)、[Phase 5](phase-5-test-entrypoints.md)。

| 模块入口 | 状态与副作用归属 | 先查测试 |
|---|---|---|
| **Chat**：[ChatView](../../../iosApp/iosApp/ChatView.swift) 的默认列表是 [NativeChatTimelineView](../../../iosApp/iosApp/Chat/Timeline/NativeChatTimelineView.swift)；[ChatViewModel](../../../iosApp/iosApp/ChatViewModel.swift) 发起运行。 | `ChatConversationRunRegistry` 持会话/run 映射；`ChatKernelRunHost` 持 run、取消与终态认领；消息写入 `IOSConversationStore`。 | `ChatNativeTimelineReplayHistoryTests`、`ChatNativeTimelineReplayCompletionTests`、`IOSChatKernelRunHostTests` |
| **AgentRuntime**：[IOSAgentToolEngine](../../../iosApp/iosApp/IOSAgentToolEngine.swift) → [ChatToolRuntime](../../../iosApp/iosApp/ChatToolRuntime.swift)；子线程入口是 [IOSThreadOrchestrationToolService](../../../iosApp/iosApp/IOSThreadOrchestrationToolService.swift)。 | Engine 持 transcript/执行器；`ChatRunKernelAdapter` 持审批与快照序号；ToolRuntime 分发工具；编排服务持目标会话 FIFO。插件/Recipe 包由各自 FileStore 写入。 | `IOSAgentToolEngineTransactionTests`、`IOSOrchestrationToolTests` |
| **WebMount**：[WebMountView](../../../iosApp/iosApp/WebMount/Presentation/WebMountView.swift) 和工具共用 [IOSWebMountController](../../../iosApp/iosApp/WebMount/IOSWebMountController.swift)。 | Controller 路由；`IOSWebMountRegistry` 存站点/记忆，`IOSWebMountSessionStore` 持会话/租约，`IOSWebMountWKRuntime` 持 WKWebView 与导航。 | `IOSWebMountRegistryPolicyTests`、`IOSWebMountSessionToolTests`、`IOSWebMountWKRuntimeTests` |
| **Novel Session**：[NovelSessionViewModel](../../../iosApp/iosApp/NovelCreation/NovelSessionViewModel.swift)、[NovelCreationViewModel](../../../iosApp/iosApp/NovelCreation/NovelCreationViewModel.swift)。 | Session VM 持 binding token、run、流消费和可见终态；Creation VM 持选择/草稿/mutation gate，命令交 `DefaultNovelCreation`。 | `NovelSessionRunOwnershipTests`、`NovelSessionReplayTests`、`NovelCreationWorkspaceMutationTests` |
| **Novel domain**：[DefaultNovelCreation](../../../iosApp/iosApp/NovelCreation/NovelCreation.swift)、[NovelFactTransactionReducer](../../../iosApp/iosApp/NovelCreation/NovelFactTransactions.swift)、[NovelDocumentValidator](../../../iosApp/iosApp/NovelCreation/NovelDocumentValidator.swift)。 | actor 持事务授权，reducer/validator 判合法转移；[NovelFileProjectRepository](../../../iosApp/iosApp/NovelCreation/NovelProjectRepository.swift) 独占项目文档/sidecar 写入与 revision/CAS。 | `NovelFactTransactionLifecycleTests`、`NovelProjectRepositoryTests` |
| **Novel generation**：[NovelGenerationLifecycle](../../../iosApp/iosApp/NovelCreation/NovelGenerationLifecycle.swift) 的 `startGeneration`。 | 同一 `DefaultNovelCreation` actor 持 run/attempt、FIFO、取消和 terminal claim；`NovelLiveModelAdapter` 接模型流，repository 落 durable 结果。 | `NovelGenerationLifecycleTests`、`NovelGenerationRecoveryTests` |
| **Settings**：[ProviderDetailView](../../../iosApp/iosApp/ProviderDetailView.swift)、[RuntimeEnvironmentView](../../../iosApp/iosApp/RuntimeEnvironmentView.swift) 编辑；[IOSSharedSettingsStore](../../../iosApp/iosApp/IOSSharedSettingsStore.swift) 提交。 | 页面持 draft/探测；SharedSettingsStore 持共享设置快照、provider 凭据写回与回滚，原 `SettingsStore` 持其设置。 | `IOSSettingsWiringTests`、`IOSSharedSettingsStoreProvidersWriteBackTests` |
| **Permissions**：[ToolPermissionsView](../../../iosApp/iosApp/ToolPermissionsView.swift) 读 [IOSCapabilityRegistry](../../../iosApp/iosApp/Infrastructure/Permissions/IOSCapabilityRegistry.swift)。 | Registry 管目录；`IOSPermissionStore` 存 policy/审批；[IOSSystemPermissionCoordinator](../../../iosApp/iosApp/IOSSystemPermissionCoordinator.swift) 缓存状态、分发系统请求。 | `IOSCapabilityRegistryTests`、`IOSPermissionStoreTests`、`IOSSystemPermissionCoordinatorTests` |
| **Storage**：[IOSConversationStore](../../../iosApp/iosApp/IOSConversationStore.swift)、[IOSWorkspaceStore](../../../iosApp/iosApp/Infrastructure/Workspace/IOSWorkspaceStore.swift)、[DocumentAccessStore](../../../iosApp/iosApp/DocumentAccessStore.swift)。 | ConversationStore 持会话快照、写序列及唯一 `persist`（底层 KMP JSON）；WorkspaceStore 写文件/工件清单；DocumentAccessStore 管选中文件读取。 | `IOSConversationStorePersistenceTests`、`IOSConversationStoreConcurrencyTests`、`DocumentAccessStoreTests` |
| **Background**：[IOSChatBackgroundGenerationCoordinator](../../../iosApp/iosApp/IOSChatBackgroundGenerationCoordinator.swift)，执行/恢复/终态在 [Chat/Background](../../../iosApp/iosApp/Chat/Background)。 | 同一 `@MainActor` coordinator 持 job/run/BGTask、claim/finish；终态先 durable 落盘再结束系统任务。 | `IOSChatBackgroundExecutionTests`、`IOSChatBackgroundSuspensionTests` |
| **Council**：[CouncilChatRuntimeView](../../../iosApp/iosApp/CouncilChatRuntimeView.swift) → [CouncilChatViewModel](../../../iosApp/iosApp/Council/CouncilChatViewModel.swift) → [IOSCouncilRoomRunner](../../../iosApp/iosApp/CouncilRunner.swift)。 | VM 持 discussion/消息/归档/后台 lease；Runner 持 provider 执行 generation/任务 ID；`CouncilRoomArchiveStore` 写归档。 | `IOSCouncilRoomExecutionTests`、`IOSCouncilRuntimeOwnershipTests` |
| **MiniApp**：[MiniAppRunnerView](../../../iosApp/iosApp/MiniAppRunnerView.swift)、[IOSMiniAppRepository](../../../iosApp/iosApp/IOSMiniAppRepository.swift)。 | Runner 持 app/bridge/宿主确认；grants 组件只回调，授权由 Runner `setGrant` → Repository 持久化；`MiniAppAIRunRecovery` 按 run ID 记中断。 | `IOSMiniAppRepositoryTests`、`IOSMiniAppBridgeRuntimeTests` |

**Target 边界：**[主工程](../../../iosApp/project.yml) 递归收录 `iosApp/`；[Novel](../../../iosApp/NovelApp/project.yml) 收录 `NovelCreation/` 并显式借用 Chat/GenerativeUI 等源；[DeepRead](../../../iosApp/DeepReadApp/project.yml) 只收录自己的目录及指定共用源。新增借用源需补对应 YAML 并分别编译。这是 target 内逻辑模块化；`Shared.framework` 仍由本仓 Gradle `:shared:link…Framework…` 生成，Core 尚非独立制品。
